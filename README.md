# Welcome to BRAJ-CLIENT-PORTAL

## Project info

BRAJ-CLIENT-PORTAL is a secure, web-based client portal designed to provide customers with centralized access to services, information, and communication tools. The platform enables clients to view and manage their accounts, track requests, exchange documents, and interact efficiently with the organization through a single, user-friendly interface.

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
